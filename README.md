### About

I'm a freelance **Laravel & Filament** developer based in Morocco. Since 2023 I've shipped web platforms, installable web apps (PWAs) and admin panels for teams in **Saudi Arabia, the UK and Palestine**, many of them in Arabic with full RTL support.

### Now building

**[FilamentCraft](https://filamentcraft.dev)** is a commercial, Shopify-style visual website builder for Filament 4 & 5. It lets you drag sections onto a live canvas, build your own sections without code, and publish multi-tenant, multilingual sites with RTL support.
